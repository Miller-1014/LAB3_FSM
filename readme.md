# LAB3_FSM - 有限狀態機控制系統

本專案基於 STM32 微控制器實作三狀態有限狀態機（Finite State Machine, FSM），整合非阻塞計時（Non-blocking）、外部中斷（EXTI）及軟體去彈跳機制，實現燈號模式控制。

## 硬體與腳位配置

依據程式碼與周邊硬體設定，腳位定義如下：

### 輸出腳位（LED 指示燈）
| 腳位 | 標籤 | 輸出設備 | 動作行為 |
| :--- | :--- | :--- | :--- |
| `GPIOC Pin 8` | green_Pin | 綠色 LED | 正常模式以 1Hz 頻率閃爍 |
| `GPIOC Pin 5` | yellow_Pin | 黃色 LED | 警告模式以 2Hz 頻率閃爍 |
| `GPIOC Pin 6` | red_Pin | 紅色 LED | 緊急模式常亮 |

### 輸入腳位（按鈕開關）
| 腳位 | 標籤 | 輸入模式 | 功能說明 |
| :--- | :--- | :--- | :--- |
| `GPIOC Pin 9` | mode_Pin | GPIO Input (Pull-Up) | 模式切換鍵（輪詢偵測 + 50ms 軟體防彈跳） |
| `GPIOC Pin 13` | BUTTON_USER | GPIO_MODE_IT_RISING | 緊急停止鍵（EXTI 外部中斷觸發） |

## 狀態機架構說明

系統定義三種運行狀態（State）：

1. **NORMAL（正常模式）**
   - 狀態代碼：`STATE_NORMAL (0)`
   - 綠燈以 1Hz 閃爍（每 500ms 翻轉一次狀態），黃燈與紅燈熄滅。

2. **WARNING（警告模式）**
   - 狀態代碼：`STATE_WARNING (1)`
   - 黃燈以 2Hz 閃爍（每 250ms 翻轉一次狀態），綠燈與紅燈熄滅。
   - 具備 5 秒超時機制（Timeout）。

3. **EMERGENCY（緊急停止模式）**
   - 狀態代碼：`STATE_EMERGENCY (2)`
   - 紅燈常亮，綠燈與黃燈強制熄滅。

## 狀態轉移條件

| 當前狀態 | 觸發事件 / 條件 | 目標狀態 | 說明 |
| :--- | :--- | :--- | :--- |
| **NORMAL** | 按下模式鍵 (`PC9`) | **WARNING** | 切換至警告狀態，並重置計時器 |
| **WARNING** | 按下模式鍵 (`PC9`) | **NORMAL** | 手動解除警告狀態，返回正常運作 |
| **WARNING** | 維持警告狀態超過 5 秒 (`>= 5000ms`) | **NORMAL** | 自動超時返回正常運作 |
| **任意狀態** | 按下緊急按鈕 (`PC13`) | **EMERGENCY** | 最高優先權中斷，立即鎖定在緊急狀態 |

## 核心技術特點

1. **非阻塞式時間管理（Non-blocking Timing）**：
   - 透過 `HAL_GetTick()` 抓取系統毫秒數，取代傳統 `HAL_Delay()`，確保燈號閃爍時仍能即時響應按鍵事件。
2. **中斷立旗標機制（EXTI Callback）**：
   - `PC13` 緊急按鈕透過中斷回呼函式 `HAL_GPIO_EXTI_Callback` 僅執行 `STOP = 1` 標記，維持 ISR 簡短快速，由主迴圈依序處理狀態轉換。
3. **軟體去彈跳（Debounce）**：
   - 模式鍵偵測到下降緣後加入 50ms 驗證，避免機械按鍵微彈跳導致連續跳轉狀態。

## 操作與測試流程

1. **開機啟動**：
   - 接上電源後，綠燈開始以 1Hz 規律閃爍（每秒滅亮一次）。
2. **切換警告模式**：
   - 短按 `PC9` 模式鍵，綠燈熄滅，黃燈改以 2Hz 加速閃爍。
   - 若不按任何鍵，等待 5 秒後黃燈自動熄滅，回復為綠燈 1Hz 閃爍。
   - 若在 5 秒內再次短按 `PC9`，會提早手動回復為綠燈閃爍。
3. **觸發緊急停止**：
   - 在任意狀態下按下 `PC13` 按鈕，系統立即中斷並轉為紅燈常亮，綠燈與黃燈全部強制熄滅。
